📌 Project Overview

This project involves creating a product listing layout using HTML and CSS. The webpage displays multiple products in an organized and attractive layout, including product images, names, prices, and buttons.

🎯 Objectives

* Create a product listing page using HTML.
* Style product cards using CSS.
* Arrange products using CSS Grid or Flexbox.
* Display product images, names, and prices.
* Create a clean and responsive layout.

🛠️ Technologies Used

* HTML5 – To structure the product listing page.
* CSS3 – To style product cards and create the layout.

✨ Features

* Multiple product cards.
* Product images and names.
* Product prices and buttons.
* Consistent spacing and alignment.
* Attractive colors and styling.
* Responsive layout for different screen sizes.
* Hover effects on product cards and buttons.

🚀 How to Run

1. Open the project folder in Visual Studio Code.
2. Open index.html using Live Server.
3. View the product listing layout in your browser.
4. Resize the browser window to test responsiveness.

📚 Learning Outcomes

Through this assignment, I learned how to create product cards, arrange items using CSS Grid or Flexbox, style images and buttons, and design a responsive product listing layout.
